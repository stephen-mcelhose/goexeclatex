# goexeclatex

**goexeclatex** — the Go execut(or) for LaTeX math expressions.

A Go library for parsing and evaluating LaTeX math syntax into numeric results.

## Overview

goexeclatex takes LaTeX math expressions (e.g. `\frac{1}{2} + \sqrt{9}`) and evaluates them to numeric values. It is designed to be embeddable, extensible, and dependency-free.
